# FemtoMind — JAM gateway for LQCDMCP

This repository now holds only the JAM gateway for the LQCDMCP platform, in
[`lqcdmcp-deploy/`](lqcdmcp-deploy/). Each JAM collaborator runs their own
gateway on the JLab LQCD cluster and runs JAM fits on ifarm from a browser
panel or an AI assistant (Claude Code, Codex).

- Collaborators: start with
  [lqcdmcp-deploy/COLLABORATOR_GUIDE.md](lqcdmcp-deploy/COLLABORATOR_GUIDE.md).
- Maintainers: [lqcdmcp-deploy/README.md](lqcdmcp-deploy/README.md).

The former AWS-hosted ChatGPT app was retired on 2026-10-08. It lives in git
history (commit `7b99311` and before).
